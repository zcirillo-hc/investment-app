# Spare Change

Keep a little. It goes a long way.

A mobile-first React web app that catches spare change (round-ups on simulated purchases plus a small slice of each simulated paycheck) into a jar, sweeps the jar into a five-ETF simulated portfolio, and teaches with short lessons that unlock as things happen. Everything runs in the browser. No backend, no real money, no runtime network calls.

## Run

```
npm install
npm run dev          # http://localhost:5173
```

Requires Node 20 or newer.

## Test

```
npm run lint:copy    # fails on any em dash or en dash under src/
npm test             # Vitest unit tests (domain, state, copy rules)
npm run build        # typecheck + Vite build (prebuild runs lint:copy)
npm run e2e          # Playwright definition-of-done scenario on mobile and desktop viewports
```

The first e2e run needs a browser: `npx playwright install chromium`.

## Demo controls and URL params

Long-press the logo (600 ms) to open the demo tray, or add `?demo=1` to the URL. The tray shows the simulated date, day index, trading day index, seed and price provenance, with buttons for Next day, Skip a week, Land a paycheck, Force summer (auto / on / off) and Reset demo.

| Param | Effect |
|---|---|
| `demo=1` | Demo tray visible by default |
| `freeze=1` | No auto-advance on open (the app otherwise advances one simulated day per real day elapsed, capped at 30) |
| `start=YYYY-MM-DD` | Simulated start date, applied when onboarding completes |
| `seed=<int>` | Transaction simulator seed, applied when onboarding completes |

The e2e scenario starts at `/?demo=1&freeze=1&start=2026-06-15&seed=42`. That start date lands in summer, the first sweep happens on simulated day 5, and the first fee on day 16 (July 1).

## Price data

`src/data/prices/{VTI,VXUS,BND,VNQ,VTIP}.json` hold 400 trading-day closing series with a `source` field that the app shows in Portfolio and Settings.

- **The committed files are SYNTHETIC.** They are generated by `npm run prices:synthetic` (deterministic, seeded) and are not real market data. The UI labels them "synthetic demo data (not real market prices)".
- `npm run prices:real` fetches real daily closes from Stooq (delayed, no key) and overwrites the files with `source: "real"`. It needs network access; during the build Stooq answered with an HTML page instead of CSV, so the synthetic files were kept. If a run fails, nothing is written.

## Layout

- `src/domain/`: pure TypeScript, no React or store imports. Money is integer cents. `tick.ts` is the daily engine.
- `src/domain/interfaces.ts`: the three swappable interfaces (`TransactionSource`, `PriceSource`, `Brokerage`).
- `src/state/`: Zustand store persisted to IndexedDB (`idb-keyval`), URL params, auto-advance bootstrap.
- `src/content/`: every UI string, the eight lessons, the quiz, and tooltip definitions.
- `src/components/`, `src/screens/`: UI.
- `tests/unit/`, `tests/e2e/`: Vitest and Playwright.

Persistence is per device (IndexedDB). Settings has Export JSON, Import JSON and Reset demo. Welcome also accepts an import so a backup can be restored into a reset app.
